# 📊 위드멤버 종합 플레이스 & 리뷰 진단기

네이버 플레이스 도구 누락 현상과 리뷰 평판(매출 성장)을 한 번에 정밀 진단하는 AI 리포트 생성기입니다.

## 💡 주요 기능
- **1일 차 진단**: 플레이스 점수 예상, 상권 경쟁 강도 분석, 네이버 공식 도구 세팅 누락 진단
- **2일 차 진단**: 방문자/블로그 리뷰 문제점 파악, AI 맞춤형 답글 제안, 마케팅 솔루션 적용 시 예상 매출 산출
- **리포트 다운로드**: 결과물을 깔끔한 이미지(.png) 형태로 즉시 다운로드 가능

## 🛠️ 기술 스택
- Python 3
- Streamlit
- Google Gemini 1.5 Flash API
- HTML2Canvas (이미지 캡처)
